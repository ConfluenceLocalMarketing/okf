# llms.txt

Mullinax Ford of Kissimmee publishes an llms.txt index that tells LLMs where to find dealership knowledge, following the llms.txt standard.

## Purpose

The llms.txt file provides a lightweight text index that LLMs can consult before answering questions about the dealership, pointing to the structured API endpoints for full data.

The llms.txt file describes the dealership and links to the data endpoints exposed by the PromptGraph API, including the business profile, testimonials, prompts, vehicles and inventory sitemap.
